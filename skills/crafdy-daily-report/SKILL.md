# Crafdy Daily Report Skill

## いつ使う
日報（作業内容/出面/職人/協力会社/人工/確認依頼/承認）に関係する時。

## triggers / keywords（誤判定を減らす）
強いトリガ（ほぼ日報）:
- 日報, 作業報告, きょうの作業, 出面, 人工, 職人, 協力会社, 応援, 常用

弱いトリガ（他カテゴリと競合しやすい）:
- 人数（※現場メンバー/招待とも競合）
- 会社名（※請求先/協力会社マスタとも競合）

## support日報（常用/応援）の扱い
- 「応援」「常用」が出たら **support日報** の可能性が高い。
- ただし今回のskillは“実装方針”なので、
  - reportKind/supportType/supportCompanyName の保存
  - 単価→請求候補→下書き
  の流れを壊さないことを優先する。

## examples
- 「今日は○○現場 日報：配管 2人」
- 「○○工業2人 応援で入った」
- 「日報を確認依頼に出して」

## 複合入力の扱い（方針）
- 日報＋経費が同時に来たら、**日報を先に保存**してから、次の1問で経費を聞く（1回に聞くのは1つ）。

## 作業前に読む（固定）
- `{repoRoot}/docs/skills/main-chat-ux.md`
- `{repoRoot}/docs/skills/ai-answering-principles.md`

## 守るべき最小ルール
- 未入力の強制ではなく「要確認」で導入（既存運用を壊さない）。
- 表示・集計は後方互換補完で落ちないようにする。
