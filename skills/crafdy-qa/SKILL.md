# Crafdy Cross-cutting Q&A Skill

## いつ使う
ユーザーが「質問」をしている時（作成フローではない）。特に横断集計:
- 粗利/利益（この現場の利益は？）
- 売上/経費（今月いくら？）
- 出面（今月誰が何日出た？）
- 進捗/状況

## triggers / keywords
- 粗利, 利益, 儲け, 原価, 売上, 経費, 出面, 人工, 集計, サマリ, 何日, どのくらい

## 方針
- まず **最短の答え**を返す（Q&A型）。
- 答えに必要な前提（対象現場/期間）が欠ける場合は、**不足を1つだけ短く質問**。
- 既存データ（売上/経費/日報/出面/単価）を参照する。
