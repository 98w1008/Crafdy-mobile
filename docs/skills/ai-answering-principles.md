# AI answering principles

## 目的
クラフディのAIは、
- 帳票作成（フロー型）
- 質問応答（Q&A型）
の **両方**を担う。

## 固定ルール
- クラフディのAIは帳票作成だけでなく **質問応答も担う**。
- 想定外の質問にも答える前提（ユーザーの質問を止めない）。

## 想定する質問（例）
- この現場の粗利どのくらい？
- 今月誰が何日出た？
- 経費いくら使ってる？

## 参照すべきデータ（前提）
必要に応じて以下を参照して答える（最小実装では集計が粗くてもよい）:
- 売上
- 経費
- 日報
- 出面
- 単価
- 粗利

## 答えられない時
- 答えられない場合は、**不足データを短く1つだけ聞く**。
  - 例: 「対象期間はいつですか？（例: 2026-03）」
  - 例: 「対象現場はどれですか？」

## フロー型AIと質問応答型AIを混同しない
- フロー型（作成/入力）は、必要項目を順に聞く。
- Q&A型（質問応答）は、質問に即して **最短の答え**を返す。
- 途中で勝手にフローを始めない（ユーザーの意図を優先）。
