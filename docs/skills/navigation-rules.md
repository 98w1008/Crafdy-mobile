# Navigation rules

## 目的
- **chat を主導線**としつつ、全体導線へ迷わず戻れる構造を維持する。
- ダッシュボードは「今どこまで済んでいるか」が分かる場所にする。

## 固定ルール
- **chat を主導線**とする。
- ただし chat から **全体導線へ戻れる**こと（迷子にしない）。
- 左上メニュー or 左スワイプメニューは有力候補（将来の導入候補として保持）。
- 次に必ず迷わず行けること（入口の明確化）:
  - 現場
  - 請求書
  - 会社情報
  - テンプレ

## 変更時の注意
- 既存カードや導線を整理しても、**遷移先（route）は壊さない**。
  - 例: まとめカードで入口を統合しても、元のルートは維持する。
- dashboard は「状態（未設定/設定済み、0件/あり 等）」を最小でも出す。

## 実装メモ（運用ルール）
- 新機能追加より、迷子を減らす導線整理を優先してよい。
- 権限制御（owner/office/member/unassigned）を壊さない。
